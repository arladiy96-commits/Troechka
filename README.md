# Троечка Помощник

Отдельное Android-приложение для локальной диагностики интерфейса **Троечка Driver** (пакет `taxi.id1702`).

## Что умеет версия 0.1

- Отслеживает обновления окон «Троечки» через Android Accessibility API.
- Подсчитывает доступные элементы интерфейса, прокручиваемые области и текстовые значения цен.
- Проверяет, распознаются ли экран карточки и текст «Принять заказ».
- Сохраняет только числовую статистику на самом устройстве.

Версия **не принимает заказы**, **не нажимает кнопки**, **не просматривает сетевой трафик** и **не имеет разрешения INTERNET**. Номера клиентов, адреса и другая персональная информация не сохраняются и не передаются.

## Как получить APK

Откройте [Actions → Build diagnostic APK](https://github.com/arladiy96-commits/Troechka/actions/workflows/build-apk.yml). Выберите последний успешный запуск и скачайте артефакт `TroechkaHelper-Diagnostic`. В ZIP будет `app-debug.apk`.

Сборка использует GitHub Actions, Java 17, Android SDK 35 и Gradle 8.7.

## Как проверить

1. Установите APK на Android.
2. Откройте «Троечка Помощник» и перейдите в настройки специальных возможностей.
3. Разрешите службу **Троечка — диагностика списка**. На некоторых версиях Android для APK, установленного вручную, сначала потребуется разрешить ограниченные настройки в системной карточке приложения.
4. Откройте «Троечка Driver» → «Свободные». Пролистайте список вручную, откройте одну карточку без принятия заказа, затем вернитесь в «Помощник».
5. Сравните показатели: текстовых узлов, прокручиваемых областей, видимых цен, обнаружение карточки и текста «Принять заказ».

Если все показатели нулевые, это может означать, что приложение не отдаёт содержимое списка Accessibility или имя пакета отличается. В таком случае понадобится другая стратегия диагностики.

## Далее

После проверки Accessibility — автоматическая навигация **в режиме теста без принятия**, затем сопоставление с локальным сетевым анализатором. Реальный приём заказов не реализован и требует отдельной проверки работоспособности и правил сервиса.
