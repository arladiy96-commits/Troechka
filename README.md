# Троечка Помощник — v0.3

Нативное Android-приложение для локальной проверки списка заказов в «Троечка Driver» (taxi.id1702).

## Скачать

[Готовый APK v0.3 — успешная сборка](https://github.com/arladiy96-commits/Troechka/actions/runs/40136205430).
Внизу страницы Artifacts → TroechkaHelper-v0.3 → скачать ZIP и установить app-debug.apk.

**Важно:** Debug APK, собранные в разных запусках GitHub Actions, могут иметь разные подписи. Если Android не устанавливает обновление поверх v0.2, потребуется удалить только «Троечка Помощник», установить v0.3 и снова разрешить его службу в специальных возможностях. Оригинальную «Троечку Driver» удалять не надо.

## Как проверить скорость и полноту

1. Открой «Троечка Driver» → «Свободные».
2. В «Помощнике» нажми «Сканировать все свободные заказы». Теперь помощник ждёт реального обновления списка после каждой прокрутки, а не сразу читает старый экран.
3. Вернись и сравни число найденных карточек с количеством заказов во вкладке «Свободные».
4. Если часть адресов обрезана или заказов не хватает, нажми «Точная допроверка пропусков». При ней выполняются небольшие свайпы с перекрытием и добавляются корректно прочитанные карточки. Этот режим медленнее.
5. Выбери найденный заказ и нажми «Найти в списке и открыть»: помощник ищет от текущей позиции и определяет направление прокрутки по запомненному порядку, не сбрасывая список в начало.
6. Запиши разницу в количестве заказов и время поиска; эти сведения помогут обнаружить особенности конкретного интерфейса.

**Не принимает заказы.** Никаких сетевых запросов, перехвата PCAP, использования ползунка «Принять» или передачи персональных данных наружу нет. Вся информация о карточках живёт только в оперативной памяти и может устареть, если список изменился; всегда проверяй открытый заказ.
