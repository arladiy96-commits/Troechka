# Троечка Помощник — v0.2

Локальный Android-помощник для диагностики доступных заказов в «Троечка Driver» (пакет taxi.id1702).

## Получить APK

Проверенная сборка: https://github.com/arladiy96-commits/Troechka/actions/runs/40135175358
Внизу страницы — артефакт TroechkaHelper-v0.2, в ZIP — app-debug.apk.

Если v0.1 уже стоит, Android может отклонить обновление из-за автоматически созданных на разных GitHub-раннерах debug-ключей. Тогда удали v0.1, установи v0.2 и снова включи специальный доступ.

## Функции

- Прокрутка всего списка «Свободные» через Android Accessibility.
- Распознавание стоимости, адресов подачи и назначения, расстояний.
- Фильтры: минимальная стоимость, максимальная подача, ключевое слово в адресе.
- Повторный поиск выбранного заказа и открытие карточки с проверкой совпадений.
- Контроль наличия ползунка «Принять заказ» без его использования.
- Без перехвата сети и без разрешения INTERNET. Данные карточек хранятся только в оперативной памяти.

## Проверка

1. Включи специальный доступ «Троечка — диагностика списка».
2. Открой вкладку «Свободные» в оригинальной «Троечке».
3. Нажми в Помощнике «Сканировать все свободные заказы».
4. После прокрутки вернись в Помощник. Там будут собранные карточки и фильтры.
5. Выбери заказ и нажми «Найти в списке и открыть».
6. Проверь, что совпали стоимость и адреса. Автоматического принятия НЕТ.

Распознавание экспериментальное: количество и содержание найденных карточек надо сверить со списком вручную. Автоматизация не гарантирует корректность работы с любыми экранами приложения.
